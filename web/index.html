Settings

Normal uses a fixed pace; hardware timing is still being refined. Faster modes speed up the cursor and timers. Browsers may limit background tabs.

Keys are tapped in order, not held together. On HP 39g+, A defaults to ALPHA → VARS. Bindings are specific to each calculator.

Uses localStorage for calculator memory, not the ROM. Open the same ROM to restore. Closing may lose changes since the last save; keep exported backups.

Connections

Virtual connections inside the emulator, not USB or serial devices on your computer. Calculator file protocols are not yet implemented.
